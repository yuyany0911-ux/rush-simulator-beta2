# RUSH SIMULATOR Ver.45 (iPhone audio stability beta)

GitHub Pages向け。ZIPを解凍し、ファイルをリポジトリ直下にアップロードしてください。

変更: リール停止音・大当たり音をWeb Audio APIで事前読込・再生。RUSH STARTのタップ時に音声コンテキストを有効化。既存の音量とBGMは維持。

初回は音源読み込みが完了するまで短時間かかる場合があります。iPhone Chromeでの実機動作は未検証です。

画像・音声・動画の公開権限を確認してください。

## Ver.46
- 設定画面の説明文、保留期待度の注釈、PCプレビューの説明文を削除。
- 「全画面表示」ボタンをiPhone Chrome/Safariでも使用可能な疑似全画面レイアウトに対応。
  iOSではWebページからブラウザのアドレスバー等を完全に消すことはできない場合があります。

## Ver.48
- 大当たり音量 50% → 65%。
- 顔保留を拡大し、間隔を狭く調整。
- 左右同図柄でテンパイしたとき、左右が外側に動き中央図柄を拡大。ハズレの一部でもリーチ演出が発生（抽選確率は不変）。

## Ver.49
- リール停止音がWeb Audioで未準備の際にHTMLAudioフォールバック再生するよう修正。
- 0図柄を追加（紫色）。通常の000大当たりにも対応。
- 設定した最大出玉の大当たりの25%で、左8・中央1・右0の特殊停止。停止後約5秒フリーズ。
- 810演出は図柄の見せ方だけを変え、大当たり確率や出玉振り分けを変更しません。

## Ver.50
- 特殊810図柄のフリーズ時間を5秒から3秒へ短縮。
- ハズレ時の停止図柄を連番固定からランダムに変更。約18%のハズレは左右同図柄のリーチ外れとして表示。
- 通常大当たりは0〜9のゾロ目で停止。最大出玉時の特殊810演出の割合（25%）は変更なし。

## Ver.51
- 810図柄の停止後フリーズを3秒から1秒に変更。
- 保留を一回り大きくし、スマホ幅に収まるよう間隔を詰めました。

## Ver.52
保留のサイズ・間隔をVer.50の状態に戻しました。810停止後の1秒フリーズは維持しています。

## Ver.53
- 残り回転数の下の REMAINING SPINS を削除。
