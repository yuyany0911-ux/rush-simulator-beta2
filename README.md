# RUSH SIMULATOR Ver.45 (iPhone audio stability beta)

GitHub Pages向け。ZIPを解凍し、ファイルをリポジトリ直下にアップロードしてください。

変更: リール停止音・大当たり音をWeb Audio APIで事前読込・再生。RUSH STARTのタップ時に音声コンテキストを有効化。既存の音量とBGMは維持。

初回は音源読み込みが完了するまで短時間かかる場合があります。iPhone Chromeでの実機動作は未検証です。

画像・音声・動画の公開権限を確認してください。
